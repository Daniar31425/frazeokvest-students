# Фразеология — МОК для студентов

Отдельная студенческая версия курса. Логика обучения строго последовательная:

`материал лекции → мини-тест → следующая лекция → итоговый тест по 15 темам → сертификат`.

## Что уже есть

- регистрация по ФИО, email и паролю;
- 15 лекций и мини-тест из 3 вопросов после каждой;
- следующая лекция открывается только после результата 67% или выше;
- итоговый тест из 15 вопросов открывается после всех мини-тестов;
- сертификат выдаётся при результате итогового теста от 70%;
- уникальный пятизначный номер сертификата;
- админ-панель с ФИО, email, прогрессом, итоговым баллом и номером сертификата;
- поиск преподавателя по ФИО, email или номеру сертификата;
- RLS и проверка ответов через защищённые Supabase RPC;
- локальный демо-режим, если Supabase ещё не подключён.

## 1. Настройка Supabase

1. Создайте новый проект Supabase.
2. Откройте **Authentication → Providers → Email** и оставьте Email provider включённым.
3. Для демо без подтверждения почты отключите **Confirm email**.
4. Откройте **SQL Editor**, вставьте целиком файл `supabase/schema.sql` и нажмите **Run**.
5. В **Project Settings → API** скопируйте Project URL и publishable key. Secret/service role в сайт не вставлять.

Создайте в корне файл `.env.local`:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxxx
```

Файл `.env.local` уже исключён из Git.

## 2. Назначение преподавателя

Сначала зарегистрируйте преподавателя через сайт, затем выполните в SQL Editor:

```sql
update public.profiles
set role = 'admin'
where email = 'teacher@example.com';
```

Перезайдите в аккаунт. После этого появится админ-панель.

## 3. Локальный запуск

```bash
pnpm install
pnpm dev
```

Сборка перед публикацией:

```bash
pnpm build
```

## 4. Vercel

1. Импортируйте репозиторий `Daniar31425/frazeokvest-students` в Vercel.
2. Framework Preset: **Vite**.
3. Добавьте две переменные окружения из `.env.local` в **Settings → Environment Variables**.
4. Выполните Redeploy.
5. В Supabase откройте **Authentication → URL Configuration**:
   - Site URL: адрес проекта Vercel;
   - Redirect URLs: тот же адрес и адрес локальной разработки.

## Проверка

1. Зарегистрируйте студента.
2. Пройдите лекцию 1 и мини-тест, обновите страницу — прогресс должен сохраниться.
3. Убедитесь, что лекция 2 открылась, а остальные остаются заблокированы.
4. После 15 мини-тестов сдайте итоговый тест.
5. Проверьте сертификат и повторную сдачу: номер не должен меняться.
6. Войдите преподавателем и найдите сертификат по пятизначному номеру.
